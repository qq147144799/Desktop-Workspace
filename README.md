# 桌面工作台（DesktopWorkbench）

一个固定在屏幕**左边缘或右边缘**的工作面板，上半部分是资源管理器，下半部分是便签。
它不是「浮在最前的窗口」，而是用 Windows 的**应用栏（AppBar）**机制把自己注册成了桌面
工作区的一部分——所以任何窗口最大化时，只会填满剩下的区域，不会盖住它。

---

## 运行

需要 **Python 3.10+**、**PySide6**，只在 Windows 上可用（依赖 AppBar API）。

```bash
pip install PySide6
python main.py
```

不想留黑窗口就用 `pythonw main.py`。

想做成单文件绿色版：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "桌面工作台" --icon app.ico --add-data "app.ico;." main.py
```

> **exe 被拦的话**：Windows 的「智能应用控制（SAC）」会拦所有没有数字签名的 exe，
> 且每次重新打包指纹都变，SAC 就重新判定一次。绕开它很简单——直接跑 Python，
> 或者建一个指向 `pythonw.exe main.py` 的快捷方式（`.lnk` 不受 SAC 管）。

只允许运行一个实例，重复启动不会开出第二个面板。

## 绿色版特性

- 单文件，不装服务、不建快捷方式、不写系统目录
- 配置存在**同目录的 `SideExplorer.json`**（含便签和回收站），删掉即恢复默认
- 目录写不了（只读、U 盘、被策略保护）时自动改用 `%LOCALAPPDATA%\SideExplorer\`
- 唯一会碰注册表的是勾选「开机自动启动」（写用户级 `HKCU\...\Run`，不需要管理员）

## 菜单（右键托盘图标）

界面上不再放菜单按钮，**所有功能都在托盘图标的右键菜单里**：

| 分组 | 内容 |
| --- | --- |
| 前往 | 主目录/桌面/下载/文档/图片/视频、各个盘符、上一级、刷新、在资源管理器打开 |
| 窗口 | 收纳窗口 ▸、恢复窗口 ▸、吸附位置 ▸、总在最前、窗口宽度 ▸ |
| 显示 | 显示隐藏文件、单击打开文件、换肤 ▸ |
| 系统 | 开机自动启动、显示 / 隐藏面板、退出 |

**左键点托盘图标** = 显示 / 隐藏面板。

## 换肤

`☰ → 换肤` 里四套配色：**浅色 / 深色 / 暖沙 / 护眼绿**，点一下立刻生效并记住。

深色主题下，便签仍保持浅色"纸面"（内容色固定），保证文字始终清楚；
其余面板、列表、菜单、浮层都会跟着主题走。

## 压缩包直接浏览

**zip / 7z / rar / tar / cab / iso** 都能双击进去，像文件夹一样浏览，
地址栏会显示 `D://资料//归档.7z//子目录`。

| 格式 | 浏览 | 解压 | 改完自动写回 |
| --- | --- | --- | --- |
| `.zip` | ✅ | ✅ | ✅ 内置 zipfile |
| `.7z` `.rar` `.tar` `.cab` `.iso` … | ✅ | ✅ | ❌ 需借助本机 7-Zip，只读 |

- **双击包内文件**：解到临时目录用默认程序打开；zip 保存后**自动写回**压缩包
  （状态栏会提示「改动已存回压缩包」），其它格式会提示「不支持自动写回，改完请另存」
- 包内暂不支持重命名/删除/粘贴
- 右键压缩包：**解压到当前文件夹** / **解压到同名文件夹**
- 右键普通文件或文件夹：**压缩为 ZIP**（重名自动加 (2)）

> 7z/rar 这些靠 `C://Program Files\7-Zip\7z.exe`，没装 7-Zip 就只支持 zip。
> `.tar.gz` 这种套娃格式不在支持范围（只会看到里面那个 `.tar`）。

## 单击打开

`☰ → 单击打开文件` 勾上后，文件列表里点一下就打开，不用双击；鼠标移上去会变手型。
多选仍可用 `Ctrl` / `Shift`。

## 导航栏

```
[⌂] [↑]  [ 路径 ]                    [→]
```

- **⌂ 房子**：直接跳到「此电脑」，列出所有磁盘
- **↑**：上一级；在盘符根再点一次也是「此电脑」
- **→**：前进（配合 `Alt + ←` 后退 —— 后退没有按钮了，用快捷键或 `Backspace`）
- 快捷键：`F5` 刷新、`Backspace` 上一级、`Alt + ←/→` 后退/前进、`Ctrl + L` 定位地址栏

## 地址栏也能当计算器

地址栏里敲算式，按回车或右边的箭头，**结果显示在浏览区**（当前目录不变）：

```
1+2*3          → 7
(1+2)*3        → 9
2^10           → 1024
10/3           → 3.333333333
sqrt(16)       → 4
round(pi, 2)   → 3.14
```

- 支持 `+ - * / // % ^`、括号，全角的 `＋－×÷（）` 也认
- 函数：`abs round min max sum sqrt cbrt pow sin cos tan asin acos atan
  log log10 log2 exp floor ceil`
- 常量：`pi` `e` `tau`
- 只要输入里带 `+ - * / =`（或括号、`sqrt` 之类的函数名），就进算式界面；
  算完**地址栏自动清空**，方便接着算下一个
- **历史会记下来**：每算一次存一条（最多 60 条），浏览区列出所有算式，
  **表达式在上、结果在下面（加粗高亮）**，每行左边有个计算器小图标，
  右侧可以挂备注（右键「备注…」），备注也会存下来
- **双击**某条结果 / 右键「填回计算结果」→ 把结果插到地址栏的**光标位置**，
  原有内容保留，插完不选中
- 右键某条记录：`填回计算结果` / `填回表达式` / **备注…** / 复制结果 /
  复制表达式 / 删除这条记录 / 清空全部记录
- 算式界面下右键**空白处**：`顺序显示` / `倒序显示` / `清空地址栏`
  （排序偏好会记住）
- 记录存在配置里，重启仍在；按 ↑ 或点地址栏回到文件列表

求值走 AST 白名单，不是 `eval`，除了数字和上面这些函数什么都调不到。

## 右键菜单

**右键的命中规则和资源管理器一致**：

- 右击**图标或文件名**那一段 → 选中该条目，弹出它的专属菜单
  （如果它本来就在选中状态，就保持当前多选）
- 右击**文件名右边的空白** → 当作右键背景，弹空白菜单，并取消当前选中
- 左键点整行任何位置都会选中，和资源管理器一样

**文件/文件夹上右键**：

```
打开
在资源管理器中显示
────────
剪切 / 复制
粘贴            ← 只有对着文件夹右键才有，粘进那个文件夹
────────
解压 / 压缩为 ZIP / 添加到快捷方式
────────
重命名 / 删除
────────
复制名称 / 复制路径
```

**盘符根目录上右键**（比如 `D://`）：只保留 `打开`、`在资源管理器中显示`、
`粘贴`（有剪贴板内容时）、`添加到快捷方式`、`复制名称`、`复制路径`，
避免手滑把整个盘删了或重命名。

**空白处右键**：

```
粘贴            ← 剪贴板有文件才出现，放最前
新建 ▸
刷新
复制当前路径    ← 放最后
```

**删除不弹确认框**：按 `Del` 直接进回收站，状态栏会提示。
删错了去回收站还原即可。

**重命名是原位的**：选中后按 `F2`，文件名原地变成输入框（不弹窗），
默认只选中扩展名前面那段（`报告.docx` 只选 `报告`），文件夹则整个名字选中。
回车确认、`Esc` 取消；名字非法或重名时状态栏提示，不会真的改坏。

**压缩大文件会有进度条**：待压缩内容超过 10MB 时弹进度窗口，显示当前文件名，
可以点「取消」中止（半成品会自动删掉）。

## 吸附在左侧还是右侧

`⋯ → 吸附位置` 里选「屏幕左侧」或「屏幕右侧」，立刻生效并记住。

切到右侧后整个面板镜像过去，连拖宽度的细条也会自动跑到面板**左**边缘——从屏幕中间往右拖是变窄，
符合直觉。工作区占用同样是整条竖向区域，最大化窗口只会用剩下那部分。

## 窗口收纳

`⋯` 菜单的**头两项**就是「收纳窗口」和「恢复窗口」，展开可以选具体某个窗口，也可以一次全选：

- **收纳窗口 → 全部**：把当前所有可见窗口藏起来，连任务栏按钮一起消失，程序继续在后台跑
- **收纳窗口 → 某个窗口**：只藏那一个，不弹确认（你自己点的就是它）
- **恢复窗口 → 全部 / 某个窗口**：随时找回来；右键托盘图标也能恢复全部
- 只处理有标题的普通窗口；桌面、任务栏、输入法、UWP 宿主等会自动跳过

> **收纳后请用面板恢复，不要在这个状态下退出面板。** 待恢复的窗口列表只存在内存里，
> 面板重启后就找不回来了（那些窗口得靠任务管理器或重开程序来恢复）。

## 快捷方式可以自己定

- **添加**：在文件列表里选中任意**文件或文件夹**，右键 → **添加到快捷方式**
  （多选可以一次加多个；只在这个地方加，别处没有添加入口）
- **打开**：文件夹单击进入，文件单击用默认程序打开
- **调整**：拖住按钮左右/上下拖，松手即生效；右键可左移/右移/重命名/移除/恢复默认
- **自动换行**：一行放不下会自己换行，最多占四行高度
- 位置不存在时按钮自动置灰，不会误导

## 排序

点状态栏右侧的「名称 ↑」：名称 / 修改时间 / 大小 / 类型，各支持升序降序。
**文件夹永远排在文件前面**，名称是自然排序（`文件2` 在 `文件10` 前面）。

## 文件操作

选中一个或多个（`Ctrl` / `Shift` 多选），右键或用快捷键：

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 重命名 | `F2` | **原位改**，不弹窗；只选中主名、扩展名不选中 |
| 删除 | `Delete` | **删除到回收站**，有确认框，可还原 |
| 复制 | `Ctrl + C` | 写入系统剪贴板（CF_HDROP） |
| 剪切 | `Ctrl + X` | 同上，带"移动"标记 |
| 粘贴 | `Ctrl + V` | 复制/移动，重名自动加 `(2)` |
| 打开 | `Enter` | 文件夹进入，文件用默认程序打开 |

剪贴板和系统资源管理器是**互通**的。在地址栏里按 `Ctrl+C/X/V` 时作用于文字，不会误操作文件。

## 把文件拖出去

选中文件或文件夹，**直接拖到桌面、资源管理器窗口、聊天窗口、邮件附件区**等任何接受文件的地方，
和资源管理器的行为一致：

- **同一个盘内拖动** = 移动（源文件会被剪切走）
- **拖到别的盘** = 复制
- 按住 `Ctrl` 强制复制、按 `Shift` 强制移动
- 多选可以一起拖，拖动时会显示当前行的缩略预览
- 压缩包里的文件拖不出去（没有真实路径），会提示先解压

如果拖拽执行的是「移动」，列表会在 1.5 秒后自动刷新。

## 新建

空白处右键 → **新建**：文件夹、文本文档、Word 文档、Excel 工作表、Markdown，
以及系统里注册过的其它类型（`HKCR\*\ShellNew`）。

注册表里有模板的走模板；没有的用内置生成——docx/xlsx 是现场生成的合法 OOXML 包，
Word/Excel/WPS 都能正常打开。

## 便签

窗口下半部分是便签区，拖动中间那条细横杠调整上下比例（比例会记住）。

- **添加**：底部输入框打字回车，或点标题栏的 `＋`
- **改内容**：**双击直接在原位置编辑**（不弹窗），回车确认、Esc 放弃
- **调顺序**：直接拖住某一行上下拖，或右键「上移 / 下移」
- **改颜色**：点左侧那根色条 → 黄 / 绿 / 蓝 / 粉 / 灰
- **设提醒**：点行尾的时间位置（没设过的 hover 会显示"设提醒"），
  时间选择器**直接浮在这一行下面**，不弹到窗口外面
- **删除**：选中按 `Delete`，或右键「删除这条」→ **进回收站**，不是真删

### 回收站

`⋯ → 回收站（N）…` 打开：

- **恢复选中**（或双击条目）：便签回到列表末尾，颜色和提醒都还在
- **彻底删除**：这条就真的没了
- **清空回收站**：全部彻底删除，会再确认一次
- 回收站最多留 100 条，超出的自动丢掉最早的

「清空全部」也是移到回收站，同样能救回来。

### 提醒

到点会在**便签区顶部浮出一张卡片**（同样不弹到窗口外），可以「知道了」或「10 分钟后提醒」。
已经提醒过的不会在重启后重复弹；错过的（比如关机期间到点）会在下次启动时补提醒。

> 提醒依赖面板在运行。想让它常驻，勾上 `⋯ → 开机自动启动`。

### CSV

便签 `⋯ → 导入/导出 CSV`，格式很简单，Excel 能直接打开：

```
内容,颜色,提醒时间
买牛奶,yellow,2026-10-22 18:00
周五交周报,blue,
```

导入兼容有无表头、逗号/分号/制表符分隔、UTF-8/GBK 编码，并会问「追加」还是「替换」。

## 其他

- **宽度**：拖内侧那条细边（左右吸附都适用），或 `⋯ → 窄/中/宽`
- **总在最前**：默认开启。关掉后普通窗口能盖住面板（最大化窗口仍然不会）
- **显示隐藏文件**
- **开机自动启动**
- 点 `✕` = 隐藏到托盘，工作区立刻恢复；托盘可叫回来，右键退出

## 快捷键汇总

| 键 | 作用 |
| --- | --- |
| `Ctrl + L` | 定位到地址栏 |
| `F5` | 刷新 |
| `Backspace` | 上一级 |

## 说明

- 面板固定在**主屏**左边缘或右边缘；任务栏若在同一侧会自动让位
- 进程意外退出时 Windows 会自动回收应用栏占位，桌面不会留下空白条
- exe 是单文件打包，首次启动要解压到临时目录，约 1~2 秒

## 文件结构

```
SideExplorer/
├── main.py              入口：单实例锁、QApplication、启动窗口
├── ui.py                主窗口：分栏、文件列表、快捷位置、菜单、托盘
├── appbar.py            Win32 应用栏封装（左右两侧、宽度、位置）
├── windowtray.py        窗口收纳（隐藏 / 恢复其它窗口）
├── fileops.py           文件剪贴板、删除到回收站、复制/移动、模板新建
├── shelldrag.py         解析 Win11 拖拽的 Shell IDList → 真实路径
├── shellnew.py          系统「新建」菜单读取 + 内置 OOXML 模板
├── archive.py           压缩包浏览、解压、压缩
├── notes.py             便签数据、颜色、时间、CSV、归档
├── notes_panel.py       便签面板：列表、颜色 / 提醒 / 排序
├── theme.py             配色与样式表
├── config.py            JSON 配置读写
├── app.ico              程序图标
└── README.md
```

运行后会在同目录生成 `SideExplorer.json`（配置 + 便签 + 算式历史），
**已加入 .gitignore**，不会进仓库。

改动源码后重新打包：

```bash
python -m PyInstaller --noconfirm --onefile --windowed --name 桌面工作台 --icon app.ico main.py
```

异常日志：`%LOCALAPPDATA%\SideExplorer\error.log`
