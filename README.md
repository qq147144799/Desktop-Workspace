# 桌面工作台（DesktopWorkbench）

一个固定在屏幕**左边缘或右边缘**的工作面板，上半部分是资源管理器，下半部分是便签。
它不是「浮在最前的窗口」，而是用 Windows 的**应用栏（AppBar）**机制把自己注册成了桌面
工作区的一部分——所以任何窗口最大化时，只会填满剩下的区域，不会盖住它。

---

## 运行

### 方式一：直接跑 exe（推荐）

双击 **`桌面工作台.exe`**，无需安装 Python。

- 单文件，约 36 MB；首次启动要解压到临时目录，约 **4～6 秒**
- 配置写在 **exe 同目录的 `SideExplorer.json`**，换台机器把它一起带走就行
- 只允许运行一个实例，重复双击不会开出第二个面板

### 方式二：从源码跑

需要 **Python 3.10+**、**PySide6**，只在 Windows 上可用（依赖 AppBar API）。

```bash
pip install PySide6
python main.py
```

不想留黑窗口就用 `pythonw main.py`。

### 自己重新打包

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --clean "桌面工作台.spec"
```

仓库里带着 `桌面工作台.spec`：单文件、无控制台、图标 `app.ico`，还额外打进了
`qtbase_zh_CN.qm`（Qt 的中文翻译，少了它标准对话框的按钮会显示成 `OK / Cancel`）。
这些都在 spec 里写好了，不用每次手敲一长串参数。

**打包前先退出正在运行的面板**——`dist\桌面工作台.exe` 被占用时覆盖会失败。
一次全量构建约 1 分钟。

产物是 `dist\桌面工作台.exe`（约 38MB），复制到项目目录即可（那里有你的
`SideExplorer.json`，换到别处会生成一份新的空配置）。

> **exe 被拦的话**：Windows 的「智能应用控制（SAC）」会拦所有没有数字签名的 exe，
> 且每次重新打包指纹都变，SAC 就重新判定一次。绕开它很简单——直接跑 Python，
> 或者建一个指向 `pythonw.exe main.py` 的快捷方式（`.lnk` 不受 SAC 管）。

## 绿色版特性

- 单文件，不装服务、不建快捷方式、不写系统目录
- 配置存在**同目录的 `SideExplorer.json`**（含便签和回收站），删掉即恢复默认
- 目录写不了（只读、U 盘、被策略保护）时自动改用 `%LOCALAPPDATA%\SideExplorer\`
- 唯一会碰注册表的是勾选「开机自动启动」（写用户级 `HKCU\...\Run`，不需要管理员）

## 菜单（右键托盘图标）

界面上不再放菜单按钮，**所有功能都在托盘图标的右键菜单里**：

| 分组 | 内容 |
| --- | --- |
| 前往 | 主目录/桌面/下载/文档/图片/视频、各个盘符、上一级、刷新、在资源管理器打开 |
| 窗口 | 吸附位置 ▸、总在最前、窗口宽度 ▸ |
| 显示 | 显示隐藏文件、单击打开文件、换肤 ▸ |
| 系统 | 定时关机 ▸、开机自动启动、显示 / 隐藏面板、退出 |

**左键点托盘图标** = 显示 / 隐藏面板。

## 定时关机

托盘菜单 → **定时关机…**，选个延时（15 分钟 / 30 分钟 / 1 小时 / 1.5 小时 / 2 小时 / 4 小时，
或者自定义 1～1440 分钟），再选 **关机** 还是 **重启**，点「定时」即可。

几个要点：

- **交给 Windows 自己执行**（`shutdown /s /t`），所以关掉面板、甚至退出程序，到点照样关；
  面板自己不留计时器，也就不会因为程序崩溃而失效
- 设好之后，托盘菜单会变成 `定时关机（29:58 后执行）…`，下面多一条 **取消定时关机**；
  鼠标悬停托盘图标也能看到剩余时间
- 设置过一次再改，会先撤销旧计划再排新的（直接重排系统会报「已经在计划中」）
- 取消用 `shutdown /a`；如果系统里本来就没有计划，会提示「当前没有进行中的定时关机」
- 提前关机或重启后，残留的时间戳会在下次启动时自动清掉

## 换肤

`☰ → 换肤` 里四套配色：**浅色 / 深色 / 暖沙 / 护眼绿**，点一下立刻生效并记住。

深色主题下，便签仍保持浅色"纸面"（内容色固定），保证文字始终清楚；
其余面板、列表、菜单、浮层都会跟着主题走。

## 压缩包直接浏览

**zip / 7z / rar / tar / cab / iso** 都能双击进去，像文件夹一样浏览，
地址栏会显示 `D://资料//归档.7z//子目录`。

| 格式 | 浏览 | 解压 | 改完自动写回 |
| --- | --- | --- | --- |
| `.zip` | ✅ | ✅ | ✅ 内置 zipfile |
| `.7z` `.rar` `.tar` `.cab` `.iso` … | ✅ | ✅ | ❌ 需借助本机 7-Zip，只读 |

- **双击包内文件**：解到临时目录用默认程序打开；zip 保存后**自动写回**压缩包
  （状态栏会提示「改动已存回压缩包」），其它格式会提示「不支持自动写回，改完请另存」
- 包内暂不支持重命名/删除/粘贴
- 右键压缩包：**解压到当前文件夹** / **解压到同名文件夹**
- 右键普通文件或文件夹：**压缩为 ZIP**（重名自动加 (2)）

> 7z/rar 这些靠 `C://Program Files\7-Zip\7z.exe`，没装 7-Zip 就只支持 zip。
> `.tar.gz` 这种套娃格式不在支持范围（只会看到里面那个 `.tar`）。

## 单击打开

`☰ → 单击打开文件` 勾上后，文件列表里点一下就打开，不用双击；鼠标移上去会变手型。
多选仍可用 `Ctrl` / `Shift`。

## 导航栏

```
[⌂] [↑]  [ 路径 ]                    [→]
```

- **⌂ 房子**：直接跳到「此电脑」，列出所有磁盘
- **↑**：上一级；在盘符根再点一次也是「此电脑」
- **→**：前进（配合 `Alt + ←` 后退 —— 后退没有按钮了，用快捷键或 `Backspace`）
- 快捷键：`F5` 刷新、`Backspace` 上一级、`Alt + ←/→` 后退/前进、`Ctrl + L` 定位地址栏
- **改名和资源管理器一个逻辑**：选中一个文件后，**再点一下它的文件名**，等半秒
  （确认不是双击）就进入原位改名；这半秒里再点一下就是双击，会打开文件。
  点图标、时间或右侧空白不会触发改名
- **搜索**：`Ctrl + F`（焦点在面板任何位置都行）或右键空白处 → 搜索，
  快捷位置下面会滑出搜索条，`Esc` 或点 `✕` 收起
  - **不按回车**：只过滤当前文件夹，不发磁盘 IO，边打边出结果
  - **按回车**：连所有子孙文件夹一起搜，右上角转圈，结果右侧照样显示修改时间
    （它到底在哪个子目录，鼠标悬停看完整路径）；
    边搜边往列表里填，不会卡住界面；最多列 3000 个
  - 支持 `*` `?` 通配符：`*.jpg`、`报告*`
  - 地址栏只负责输路径，不会偷偷变成搜索

## 区域截图

**任何窗口前面都能按 `Ctrl + Shift + A`**（全局热键），或者托盘 / 标题栏右键 → 截屏 → 区域截图。

面板**不会**自动隐藏——想截哪里截哪里，面板本身也会出现在截图里。

1. 屏幕变暗、鼠标变十字，桌面冻结成一张静态图
2. 拖出选框 → 松手后选区四边四角出现**白色小方块手柄**，下方弹出工具条
   （贴底时自动翻到上方）

**选完还能改**：

- 在选区**内部拖动** = 整个框挪位置
- 拖**边或角** = 改尺寸，光标会变成对应的双向箭头
- 在选区**外面**重新拖 = 重新框一个
- 全程都有边界保护，框不会跑出屏幕

**鼠标坐标**：截图状态下光标旁边一直跟着一个 `1024, 618` 的小标签，给的是
**屏幕绝对坐标**，贴边时自动翻到光标另一侧。

| 按钮 | 快捷键 | 做什么 |
| --- | --- | --- |
| 复制 | **双击图片** / `Ctrl+C` / `Enter` | 放进剪贴板，然后关闭 |
| 固定 | `Ctrl+T` | 把截图钉在屏幕上，四周一圈**蓝色柔光** |
| 下载 | `Ctrl+S` | 弹「另存为」，默认存到**当前浏览的目录** |
| 取消 | `Esc` / 右键 | 什么都不做 |

框选过程中随时 `Esc` 或点右键取消；几乎没拖动（小于 4px）也当误触退出。

### 改快捷键

**截屏 → 设置快捷键…**，按下想要的组合键即可，存在配置里，重启还记得。

- 建议带上 `Ctrl / Alt / Shift / Win`，或者用 `F1～F12`；光秃秃的字母会被拒绝
  （不然正常打字全被吃掉）
- 留空 = 关掉这个快捷键
- 如果组合被别的程序占了，状态栏会提示「没注册上」

### 固定到屏幕

- **滚轮**缩放（0.1×～8×），光标下那个点保持不动；缩到 10% 或放到 800% 就停住
- `Ctrl + =` / `Ctrl + -` / `Ctrl + 0`（原始大小）
- 缩放时右下角会跳出一个百分比，停 0.9 秒自动消失
- **拖动移动**（按住 `Ctrl` 拖也行，图上全是字的时候用这个）
- `Esc` 关闭、右键菜单里也有「关闭」
- 右键：复制文字 / 复制全部文字 / 全选文字 / 复制图片 / 另存为 / 放大缩小 / 关闭

### 识别文字（OCR）——直接在图里选

贴图本身就像一篇文档：

| 操作 | 效果 |
| --- | --- |
| 鼠标移到字上 | 光标变成 **I 形**，表示这里能选 |
| 按住拖 | 按**单个字**选中，被选的字罩一层蓝色 |
| 双击某个字 | 选中**整行** |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制选中的文字（没选中就复制图片） |
| 拖空白处 | 移动窗口 |

识别在**贴图的同时**就丢到后台线程去跑（二十多毫秒，基本上贴上去就能选），
贴上去不会卡；识别好之后鼠标再移进去，直接就是 I 形光标。

**引擎只用一个**：Windows 自带的 `Windows.Media.Ocr`，绿色免安装。也接过 PP-OCR
（RapidOCR），中文确实更准，但要连带装进 onnxruntime + opencv 一百多兆 —— 对一个
贴边小面板来说太重，撤掉了。代价是小字会认错几个，实测数据见下。

**字框是量出来的，不是算出来的**：引擎给的是 word 级框，这里再扫一遍该区域的
像素，找出每一列有没有"墨"，按真实的字间空隙切出每个字的左右边界 —— 所以拖选能精确到
单个字，中英混排也不会越选越偏（早先按字宽均分，选到第 5 个字就会偏一个）。

> 依赖（本机已装好，都是几百 KB 的小包）：
>
> ```bash
> pip install winrt-runtime winrt-Windows.Media.Ocr winrt-Windows.Graphics.Imaging \
>             winrt-Windows.Globalization winrt-Windows.Storage.Streams winrt-Windows.Foundation
> ```
>
> 没装也不影响其它功能，只是贴图时不会变 I 形光标。

**引擎实测**（同一批界面文字，字符准确率）：

| 字号 | 原图直送 | 放大 1.5 倍 |
| --- | --- | --- |
| 13px 界面小字 | 78% | **89%** |
| 16px | 90% | **94%** |
| 22px 大标题 | 94% | **97%**（放大 2 倍可到 100%） |

所以贴图时会自动把窄图放大 1.5 倍再送去识别；横向超过 1400px 的图原样送，
超过引擎 2600px 上限（4K 截图）则一律缩小。像「桌面」认成「卓面」这种固定错字，
没有可靠办法纠正，只能认。

光晕是逐层叠出来的：贴边那一圈近似实心的浅蓝（`#6EAAFF`），往外 15px 线性淡到
透明，所以看着像图片自己发光，而不是加了个黑框。

**关于清晰度**：截图取的是物理像素。150% 缩放下，屏幕上一块 100×60 的区域
保存出来是 150×90 的图，放到别的显示器上不会发虚。

## 计算器

下半区第二个页签（`Ctrl + 2`）。敲算式回车就出结果：

```
1+2*3          → 7
(1+2)*3        → 9
2^10           → 1024
10/3           → 3.333333333
sqrt(16)       → 4
round(pi, 2)   → 3.14
```

- 支持 `+ - * / // % ^`、括号，全角的 `＋－×÷（）` 也认
- 函数：`abs round min max sum sqrt cbrt pow sin cos tan asin acos atan
  log log10 log2 exp floor ceil`
- 常量：`pi` `e` `tau`
- 算完输入框自动清空，接着算下一个；算不出来就在状态栏说一声，输入还留着
- **历史自动记下来**：每算一次存一条（最多 500 条），新的在上。
  **一行一条**：左边表达式（灰）、右边结果（加粗、右对齐），整数带千分位
- **双击**某条 → 表达式填回输入框继续改；右键还有：
  `填回输入框` / `复制结果` / `复制表达式` / `删除这条记录` / `清空全部记录`
- 记录存在配置里，重启仍在

求值走 AST 白名单，不是 `eval`，除了数字和上面这些函数什么都调不到。

> 以前这套东西挂在地址栏上（敲算式会把浏览区变成历史列表），现在搬进了独立页，
> 地址栏只负责跳路径。

## 右键菜单

**右键的命中规则和资源管理器一致**：

- 右击**图标或文件名**那一段 → 选中该条目，弹出它的专属菜单
  （如果它本来就在选中状态，就保持当前多选）
- 右击**文件名右边的空白** → 当作右键背景，弹空白菜单，并取消当前选中；
  最右边那列**修改时间**也按空白处理（点它同样弹背景菜单）
- 左键点整行任何位置都会选中，和资源管理器一样

**文件/文件夹上右键**：

```
打开
在资源管理器中显示
────────
剪切 / 复制
粘贴            ← 只有对着文件夹右键才有，粘进那个文件夹
────────
解压 / 压缩为 ZIP / 添加到快捷方式
────────
重命名 / 删除
────────
复制名称 / 复制路径
```

**盘符根目录上右键**（比如 `D://`）：只保留 `打开`、`在资源管理器中显示`、
`粘贴`（有剪贴板内容时）、`添加到快捷方式`、`复制名称`、`复制路径`，
避免手滑把整个盘删了或重命名。

**空白处右键**：

```
搜索            Ctrl+F    ← 放最前，找文件最常用
粘贴            ← 剪贴板有文件才出现
新建 ▸
刷新
复制当前路径    ← 放最后
```

**文件把列表铺满、没有空白可右键时**：状态栏右下角的 `☰` 按钮弹出
的就是这同一排菜单（搜索 / 新建 / 粘贴 / 刷新…）。

**删除不弹确认框**：按 `Del` 直接进回收站，状态栏会提示。
删错了去回收站还原即可。

**重命名是原位的**：选中后按 `F2`，文件名原地变成输入框（不弹窗），
默认只选中扩展名前面那段（`报告.docx` 只选 `报告`），文件夹则整个名字选中。
回车确认、`Esc` 取消；名字非法或重名时状态栏提示，不会真的改坏。

**压缩大文件会有进度条**：待压缩内容超过 10MB 时弹进度窗口，显示当前文件名，
可以点「取消」中止（半成品会自动删掉）。

## 吸附在左侧还是右侧

`⋯ → 吸附位置` 里选「屏幕左侧」或「屏幕右侧」，立刻生效并记住。

切到右侧后整个面板镜像过去，连拖宽度的细条也会自动跑到面板**左**边缘——从屏幕中间往右拖是变窄，
符合直觉。工作区占用同样是整条竖向区域，最大化窗口只会用剩下那部分。

## 快捷方式可以自己定

- **添加**：在文件列表里选中任意**文件或文件夹**，右键 → **添加到快捷方式**
  （多选可以一次加多个；只在这个地方加，别处没有添加入口）
- **打开**：文件夹单击进入，文件单击用默认程序打开
- **调整**：拖住按钮左右/上下拖，松手即生效；右键可左移/右移/重命名/移除/恢复默认
- **自动换行**：一行放不下会自己换行，最多占四行高度
- 位置不存在时按钮自动置灰，不会误导

## 排序

点状态栏右侧的「名称 ↑」：名称 / 修改时间 / 大小 / 类型，各支持升序降序。
**文件夹永远排在文件前面**，名称是自然排序（`文件2` 在 `文件10` 前面）。

## 列表密度

**一行一个文件**：行首图标 16px、文件名 9pt、最右边是灰色的修改时间（7.8pt）。
行高 30px，720px 高的面板能看 **12 条**。

**文件列表和 7 个页签的列表共用同一套行样式**（`list_style.py`）：行高 30、卡片左右内缩 7、
上下内缩 2、圆角 6、正文 9pt、右侧灰字 7.8pt、文字左边距 9。改那几个常量，所有列表一起变。
截屏管理器因为要放缩略图，行高单独用 48。

- 时间只用三档，越久远说得越粗，省下的宽度全给文件名：

  | 修改时间 | 列表里显示 |
  | --- | --- |
  | 今天 | `20:31` |
  | 一年以内 | `10/30` |
  | 超过去年的今天 | `2024` |

- **文件大小和完整时间不占行内空间**：选中单个文件时，大小在状态栏**左边**、
  完整时间 `2026-10-31 20:31` 在**右边**（紧贴排序按钮，右边缘对齐）；
  选文件夹时左边显示 `文件夹`。多选是 `已选 3 项 · 共 56.0 KB`（含文件夹会注明个数），
  右边不显示时间；取消选中就退回 `41 个项目 · 3 个文件夹`
- 递归搜索的结果和普通浏览一个样：右侧仍是**修改时间**，悬停提示也还是那条**完整路径**
  （搜索结果的路径本身就带子目录），不额外加说明文字
- 面板太窄（放不下时间列）时自动只留文件名，不会把名字挤没
- 一行就是一个条目：点图标、点名、点时间都算选中/打开；只有列表下方空白才算背景

行内几何都收在 `ui.py` 顶部的四个常量里 —— `ROW_HEIGHT` / `ROW_ICON` / `ROW_ICON_X` / `ROW_TEXT_X`，
绘制、右键命中、重命名输入框三处都读同一套值，想再调密一点只改这几行就行。

## 文件操作

选中一个或多个（`Ctrl` / `Shift` 多选），右键或用快捷键：

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 重命名 | `F2` | **原位改**，不弹窗；只选中主名、扩展名不选中 |
| 删除 | `Delete` | **删除到回收站**，有确认框，可还原 |
| 复制 | `Ctrl + C` | 写入系统剪贴板（CF_HDROP） |
| 剪切 | `Ctrl + X` | 同上，带"移动"标记 |
| 粘贴 | `Ctrl + V` | 复制/移动，重名自动加 `(2)` |
| 打开 | `Enter` | 文件夹进入，文件用默认程序打开 |

剪贴板和系统资源管理器是**互通**的。在地址栏里按 `Ctrl+C/X/V` 时作用于文字，不会误操作文件。

## 把文件拖出去

选中文件或文件夹，**直接拖到桌面、资源管理器窗口、聊天窗口、邮件附件区**等任何接受文件的地方，
和资源管理器的行为一致：

- **同一个盘内拖动** = 移动（源文件会被剪切走）
- **拖到别的盘** = 复制
- 按住 `Ctrl` 强制复制、按 `Shift` 强制移动
- 多选可以一起拖，拖动时会显示当前行的缩略预览
- 压缩包里的文件拖不出去（没有真实路径），会提示先解压

如果拖拽执行的是「移动」，列表会在 1.5 秒后自动刷新。

## 以邮件附件发送

右键**文件** → **以邮件附件发送**，会打开系统默认邮件客户端的写邮件窗口，选中的文件已经
挂成附件，填上收件人就能发。多选时菜单会写成「以邮件附件发送（3 个文件）」。

- **Foxmail**：走它自己那条 `Foxmail.exe /min <文件…>`——正是它注册到「发送到」菜单里的
  命令，实测 0.5 秒弹出写邮件窗口，附件挂好，主题还自动取了文件名
- **其它客户端**：`mailto:` 打开写邮件，同时把文件放进剪贴板（和面板里 `Ctrl+C` 是同一套
  CF_HDROP），按一次 `Ctrl+V` 就挂成附件
- **文件夹不显示这一项**（不能当附件）；压缩包里的虚拟路径没有真实文件，同样不显示
- 没有用 Simple MAPI：64 位进程去加载 32 位的 `FMMAPI32.dll` 时通时不通，本机
  `Mail Recipient.MAPIMail` 直接报 1155（没有关联应用），所以改用「识别默认客户端 + 它自己的
  命令行」，认不出来再退到剪贴板

## 新建

空白处右键 → **新建**：文件夹、文本文档、Word 文档、Excel 工作表、Markdown，
以及系统里注册过的其它类型（`HKCR\*\ShellNew`）。

注册表里有模板的走模板；没有的用内置生成——docx/xlsx 是现场生成的合法 OOXML 包，
Word/Excel/WPS 都能正常打开。

## 工作台（下半区）

窗口下半部分是一排图标页签，拖动中间那条细横杠调整上下比例（比例会记住）：

| 页签 | 说明 |
| --- | --- |
| 待办事项 | 一行一条，带颜色和提醒 |
| 日历 | 只读月历，有提醒的日子打点 |
| 记事本 | 一个长文本框，边打边存 |
| 计算器 | 算式 + 历史（见上一节） |
| 剪切板 | 复制过的文字，点一下复制回去 |
| 截屏管理器 | 截图历史（最多 500 条），点一下贴回屏幕 |
| 窗口管理器 | 把别的窗口贴到工作区的左半 / 右半、最大最小化、关闭、收起 |

为什么用图标不用文字：面板最窄能拖到 260px，七个两字页签塞不下、会被挤成省略号。

- 图标 18px，每格宽度**随面板宽度均分**（29 ~ 40px 之间），拖宽了不会右边空一大块
- 页签条左右各留 8px 外边距，第一个图标不会贴住面板边缘
- 选中是淡色底 + 细描边 + 蓝色图标，悬停是浅灰底
- **鼠标一移上去就显示板块名**（不延迟）：待办事项 / 日历 / 记事本 / 计算器 /
  剪切板 / 截屏管理器 / 窗口管理器；`Ctrl + 1` ~ `Ctrl + 7` 按同样顺序直达

右上角只剩一个 `⋯`，点开是当前页的菜单（新建待办、回到今天、区域截图…都在里面）。

### 窗口管理器

把**正在运行的其它窗口**贴到工作区的左半或右半 —— 就是 Win7 那个拖到屏幕边缘
自动占半屏的动作，只不过不用拖。面板是应用栏，系统算工作区时已经扣掉了面板宽度，
所以这里贴的「左半」正好是面板右侧剩余空间的左半。

- **每个窗口一行**（不按程序合并 —— 浏览器开三个窗口就是三行，能分别分屏），
  显示的是窗口标题
- 右边一条**六格按钮**（连成一个整体，共 114px）：
  五个图形按钮：`_` 最小化 · `<`/`>` 贴左/右半屏 · `□` 最大化 · `✕` 关闭；
- **再点同一个键就是还原**；当前处于哪个状态，对应格就蓝底高亮
  （最大化 → `大` 亮，最小化 → `小` 亮，贴边的 → `左`/`右` 亮）
- `关` 走程序自己的关闭流程（该弹「要保存吗」还是会弹），关掉后从列表消失
- **后台运行**在右键菜单里：把窗口收起来（`SW_HIDE`），**不会往托盘塞图标**；
  窗口仍然留在列表里并变成灰色，右键 → `叫回前台` 就能放回来
- **列表顺序可以拖动调整**，刷新（切页/开新窗口）不会把你的顺序打乱，
  新出现的窗口只会追加到末尾
- 点标题只选中，不会动窗口 —— 免得手一抖把别人的窗口挪走
- `⋯` 里有「全部还原」，一键把所有贴过边的窗口放回去
- 贴完窗口会**跳到最前面**，不会白贴；最小化的窗口点 `左`/`右`/`大` 会先叫回来再操作

技术上是 `SetWindowPos` 到 `SPI_GETWORKAREA` 的左右两半（物理像素），
原位用 `GetWindowPlacement` / `SetWindowPlacement` 存取。

### 待办事项

- **添加**：底部输入框打字回车，或点右上角的 `＋`（一条便签就是一行）
- **搜索**：`Ctrl + F` 唤起搜索条（列表上方浮出），输入即过滤，`Esc` 收起；
  右上角 `⋯` 里也有入口
- **改内容**：**双击直接在原位置编辑**（不弹窗），回车确认、Esc 放弃
- **调顺序**：直接拖住某一行上下拖，或右键「上移 / 下移」
- **改颜色**：点左侧那根色条 → 黄 / 绿 / 蓝 / 粉 / 灰
- **设提醒**：点行尾的时间位置（没设过的 hover 会显示"设提醒"），
  时间选择器**直接浮在这一行下面**，不弹到窗口外面
- **删除**：选中按 `Delete`，或右键「删除这条」→ **进回收站**，不是真删

### 回收站

`⋯ → 回收站（N）…` 打开：

- **恢复选中**（或双击条目）：便签回到列表末尾，颜色和提醒都还在
- **彻底删除**：这条就真的没了
- **清空回收站**：全部彻底删除，会再确认一次
- 回收站最多留 100 条，超出的自动丢掉最早的

「清空全部」也是移到回收站，同样能救回来。

### 提醒

到点会在**便签区顶部浮出一张卡片**（同样不弹到窗口外），可以「知道了」或「10 分钟后提醒」。
已经提醒过的不会在重启后重复弹；错过的（比如关机期间到点）会在下次启动时补提醒。

> 提醒依赖面板在运行。想让它常驻，勾上 `⋯ → 开机自动启动`。

### CSV

便签 `⋯ → 导入/导出 CSV`，格式很简单，Excel 能直接打开：

```
内容,颜色,提醒时间
买牛奶,yellow,2026-10-22 18:00
周五交周报,blue,
```

导入兼容有无表头、逗号/分号/制表符分隔、UTF-8/GBK 编码，并会问「追加」还是「替换」。

### 记事本

一个长文本框，没有「新建 / 保存 / 另存为」—— 停手 0.8 秒就写进配置，
切页、关面板都会再补存一次，所以随手写点东西不会丢。

- 右下角实时显示 `字数 · 行数`
- `Tab` 插入制表符（不跳焦点），写代码片段顺手
- `⋯` 里有：**导入 txt…** / **导出为 txt…** / 复制全部 / 全选 / 清空（清空用剪切，`Ctrl + Z` 能撤回）
- **导入**会替换当前内容（替换后还能 `Ctrl + Z` 撤回）；编码自动认
  UTF-8 / UTF-8 BOM / UTF-16 / GBK，换行统一成 LF
- **导出**写 UTF-8 + CRLF，双击用 Windows 记事本打开就是正常的多行

### 日历

只读月历。**有便签提醒的日子下面有个小点**；点某一天，**当天那几条便签会列在日历下方**
（最多露 3 行，多的往下滚），不再挤在状态栏一行里。

- 今天是蓝色实心圆，周末日期颜色淡一些
- 左上 / 右上的 `‹` `›` 翻月，`＋` 回到今天
- 只读是故意的：要加提醒去便签页，省得这里再暴露一套写入路径

### 截屏管理器

截图历史，按时间倒序排（最多 500 条）：

- **点左边那张缩略图** = 把这张图贴到屏幕上，**左上角对齐面板左上角、宽度跟面板当前
  宽度一样**（之后照样能拖动、滚轮缩放、框选文字；Esc 关闭）；
  点时间、点尺寸、点右边空白**只是选中，不会贴**
- **右键**：贴到屏幕上 / 复制图片 / 另存为… / 在资源管理器中显示 / 删除这一张
- **截完自动出现在列表里**（按 `Ctrl+Shift+A` 截完不用手动刷新）
- `⋯` 菜单里还有：
  **快捷键设定…**（弹出的组合框按一下你想用的键，括号里显示当前生效的组合；
  留空 = 关掉快捷键）/ **清理固定屏幕上的截屏**（一键关掉所有贴图，标题会显示当前张数）/
  打开截图文件夹 / 清空全部截图记录
- 没截过图时提示你**实际生效的快捷键**（默认 `Ctrl+Shift+A`，改过会跟着变；
  快捷键关掉了就提示从 `⋯` → 区域截图开始）

### 剪切板

面板运行期间自动记录复制过的**文字**（图片归截屏管理器管）：

- 最多 100 条，连着复制同一段只留一条
- **点一下 = 复制回剪贴板**，直接粘到别处
- **一行一条**：左边是复制的文字（第一行），右边是复制时间；右键可以删除单条
- `⋯` → 清空剪切板历史
- 只记录**本次运行期间**的复制动作，关掉面板就不再监听

截图本体存在 `%LOCALAPPDATA%\SideExplorer\shots`，磁盘留最近 500 张；
内存里只缓存看得见的那几十张缩略图，不会因为条数多把内存吃光。

## 说明

- 面板固定在**主屏**左边缘或右边缘；任务栏若在同一侧会自动让位
- 进程意外退出时 Windows 会自动回收应用栏占位，桌面不会留下空白条
- exe 是单文件打包，首次启动要解压到临时目录，约 1~2 秒
